# v2l4_learn

Jetson Orin Nano 排线摄像头（IMX219）学习项目：网页实时预览、控制、录制与回放。

## 功能

- 网页实时预览（MJPEG）
- 旋转 / 缩放 / 复位
- **锁定当前设置**（下次打开自动恢复）
- 去红边强度调节
- **时间 OSD**（可开关）
- 截图、录制
- **回放页**：按录像列表选择，时间轴拖动回放
- 局域网 / Tailscale 访问

## 快速开始

```bash
cd /home/lht/sync/v2l4_learn
./start.sh
```

- 实时预览：`http://<IP>:8080`
- 回放页面：`http://<IP>:8080/playback`

## 页面说明

### 实时预览 `/`

| 操作 | 说明 |
|------|------|
| 左转/右转/放大/缩小/复位 | 调整观看视角 |
| 锁定当前设置 | 保存旋转、缩放、去红边、OSD 到 `settings.json` |
| 显示时间 | 画面左上角叠加当前时间 |
| 截图 / 录制 | 保存到 `snapshots/`、`recordings/` |

### 回放 `/playback`

1. 左侧选一段录像  
2. 新录像直接是 H.264/MP4，可直接时间轴回放  
3. 旧的 AVI 首次打开时会自动转成 MP4  

## 录制占用评估

### 旧方案（已废弃）：MJPG/AVI
几乎是“每帧一张 JPEG”，压缩很弱 → 约 **60 MB/分钟**。

### 新方案（当前）：H.264/MP4（ffmpeg libx264，CRF 23）

| 项目 | 大约数值 |
|------|----------|
| 磁盘占用 | 约 **5~12 MB/分钟**（比原来小约 5~10 倍） |
| 格式 | `recordings/*.mp4`，浏览器可直接播 |
| 程序内存 | 约 **280 MB** 量级，录制主要写磁盘 |

如需更小文件，可把 CRF 调到 26~28（更糊一点）；要更清晰可调到 20。

## 麦克风（MIC）支持情况

**当前版本：不支持录音频。**

原因：
- 现在是纯视频预览 + H.264 录像（无音轨）
- 网页预览流本身也不带声音

硬件上：
- Jetson 有板载音频接口路径（APE）
- **当前没检测到 USB 麦克风**
- 以后可接 **USB 麦克风** 或板载 MIC，用 ffmpeg 把音视频合成进 MP4

结论：**可以支持，但还没做。** 你要的话我下一步可以加“录像带声音”。

## 文件说明

| 路径 | 作用 |
|------|------|
| `app.py` | 主程序 |
| `start.sh` | 启动脚本 |
| `settings.json` | 锁定的视角/去红边/OSD 设置 |
| `snapshots/` | 截图 |
| `recordings/*.mp4` | H.264 录像（当前） |
| `recordings/*.avi` | 旧版 MJPG 录像（如有） |

## 常见接口

| 接口 | 说明 |
|------|------|
| `/api/settings` | 获取/保存锁定设置 |
| `/api/color` | 去红边 |
| `/api/playback/list` | 回放列表 |
| `/api/playback/open/<id>` | 打开并转码可播文件 |

## 已知限制

- 去红边是软件补偿，不能完全等同原厂校正
- 回放依赖 ffmpeg 转 MP4（本机已具备）
- 暂无账号密码、暂无音频
